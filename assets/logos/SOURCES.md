Logo assets for decorative internship-card watermarks, added on 2026-10-20.
Files are kept locally to avoid third-party requests when viewing the portfolio.
CSS filters render the logos in a subtle theme-matched monochrome.

Current Baidu, Kimi and Zhipu watermarks use the user's reference images,
copied unchanged on 2026-10-20:

- `baidu-symbol.png`: standalone blue paw with the white "du" cutout.
- `kimi-wordmark.png`: uppercase KIMI wordmark.
- `zhipu-symbol.png`: standalone Z symbol.

in both themes. BAIC uses the official asset below.
